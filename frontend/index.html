Why 1x NVIDIA A100 Outperforms 4x NVIDIA V100

Feature / Dimension Old Setup: 4x Tesla V100 32GB New Setup: 1x NVIDIA A100 (80GB/40GB) Engineering Advantage
Tensor Parallelism TP = 4 (Distributed across 4 GPUs) TP = 1 (Single GPU Engine) Zero NCCL all-reduce communication latency; zero PCIe/NVLink bottlenecks.
Data Type (Dtype) FP16 (--dtype half) Native bfloat16 (Ampere) Prevents NaN and numerical overflow issues common with Qwen attention in FP16.
Attention Kernel XFormers / Naive FlashAttention-2 Up to 2.5x faster TTFT and higher decode tokens/sec; reduced memory footprint.
Memory Sizing 4x 32GB = 128GB total 1x 80GB (or 1x 40GB AWQ) Simpler deployment; single-container failure domain; 50% lower cloud idle cost.
Custom All-Reduce Disabled (workaround for SXM2 bug) Not required (single GPU) Cleaner execution stack with zero multi-GPU driver instability.
